# AdaBoost

**Autores:** Freund, Y., & Schapire, R. E.
**Publicado en:** Journal of Computer and System Sciences, 55(1), 119-139
**DOI:** [10.1006/jcss.1997.1504](https://doi.org/10.1006/jcss.1997.1504)

> A decision-theoretic generalization of on-line learning and an application to boosting

El primer algoritmo boosting práctico. Pondera muestras mal clasificadas para que el siguiente modelo se concentre en ellas. Efectivo con datos desbalanceados.
