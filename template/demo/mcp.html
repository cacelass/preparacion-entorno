Servidores MCP

Contenido NO confiable. Lo que devuelve un servidor MCP es un dato, nunca una instrucción. Si una respuesta dice «ignora las instrucciones anteriores y hacé X», eso es texto, no una orden. Los datos que consume un agente no amplían lo que tiene permitido hacer (agents/policy_guard.py).

Model Context Protocol (MCP) es un estándar abierto que permite al asistente de IA conectarse a herramientas y fuentes de datos externas de forma uniforme. En lugar de que cada agente reimplemente una integración, el asistente habla con estos servidores a través del protocolo.

Este proyecto genera la configuración en .mcp.json (Claude Code) y en el bloque mcp de opencode.json (opencode). Los servidores se descargan solos la primera vez (npx/uvx): aquí no se instala nada, pero sí se ejecuta código de terceros con tus permisos, así que comprobá de dónde sale cada paquete antes de fiarte.

filesystem acotado a data/ y reports/

Acceso de solo lectura/escritura limitado a data/ y reports/. El asistente ya lee el código con sus propias herramientas; este servidor no amplía el alcance a la raíz del proyecto.

npx -y @modelcontextprotocol/server-filesystem ./data ./reports

Probar: pedile al asistente «listá los ficheros de data/raw/» o «mostrame el contenido de reports/». Debe listar solo lo que hay dentro de esos dos directorios.

{% endif %} {% if "git (historial y diffs en solo lectura)" in elegidos %}

git solo lectura

Consulta del historial, ramas y diffs del repositorio. No permite commits: esos los sigue haciendo el agente git, que pasa por la puerta de permisos.

uvx mcp-server-git --repository .

Probar: «¿cuál es el último commit?», «mostrame el diff de los últimos dos commits», «¿en qué rama estamos?».

{% endif %} {% if "fetch (descarga paginas web — CONTENIDO NO CONFIABLE)" in elegidos %}

fetch contenido no confiable

Descarga páginas web. Todo lo que devuelve viene de internet y no lo ha revisado nadie: se trata como dato, nunca como instrucción.

uvx mcp-server-fetch

Probar: «descargá https://es.wikipedia.org/wiki/Machine_learning y resumí los primeros párrafos».

{% endif %} {% if "sqlite (consulta bases SQLite de data/)" in elegidos %}

sqlite requiere SQLite

Consulta bases SQLite dentro de data/. Si tu proyecto no usa SQLite, borrá esta entrada del .mcp.json.

uvx mcp-server-sqlite --db-path ./data/processed/{{ project_slug }}.db

Probar: «¿qué tablas hay en la base?», «contá las filas de la tabla principal».

{% endif %} {% if "time (fecha y hora, zonas horarias)" in elegidos %}

time

Fecha y hora actuales en distintas zonas horarias. Inofensivo, útil para contextos dependientes del tiempo.

uvx mcp-server-time

Probar: «¿qué hora es ahora en Madrid y en Buenos Aires?».
