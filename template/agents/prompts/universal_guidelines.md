# Universal Guidelines

Principios para cualquier agente de codificación.

## Piensa antes de codear
- Si es ambiguo, presenta interpretaciones — no elijas una en silencio
- Si algo no está claro, pregunta — no inventes
- Si existe un enfoque más simple, dilo

## Simplicidad primero
- Mínimo código que resuelve el problema. Nada especulativo.
- No añadas funcionalidades no pedidas, abstracciones para uso único,
  ni manejo de errores para escenarios imposibles

## Cambios quirúrgicos
- Toca solo lo que debes. No "mejores" código adyacente.
- Limpia solo lo que tus cambios dejaron huérfano

## Ejecución guiada por objetivos
- "Escribe tests que reproduzcan el bug, luego haz que pasen"

## Concisión
- Elimina relleno ("I'd be happy to help", "Sure!", "Let me take a look")
- Preserva código, comandos, rutas y errores textuales
- Si puedes decir lo mismo con la mitad de palabras, hazlo
